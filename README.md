# Dragon Warrior Randomizer - Archipelago edition #

This is a fork of [juef's unofficial Dragon Warrior Randomizer](https://github.com/juef17/dwrandomizer), made specifically for Archipelago. It is not intended for use on it's own, instead it is built using Cython to create a Python wrapper suitable for use within Archipelago. You can find that over at (TBD when I implement it lol)

If you're interested in building it yourself, the Makefile I used to build the wrapper is included (make sure you have Cython installed), just be sure to uncomment it and replace the file paths with your own.
